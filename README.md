# Kasanoma ASR  
### Personalized, Code-Switched & Edge-Deployable Speech Recognition for Atypical African Speech

Kasanoma is a research project focused on building:
1. Personalized ASR for atypical/disordered speech  
2. Code-switched English–Twi/Yoruba/Ga models  
3. Edge-deployable inference on Raspberry Pi  
4. Assistive features for disabled users

English-Twi Code-Switching Speech Dataset
A studio-recorded bilingual speech corpus for English-Twi (Akan) code-switching, designed to support research in Automated Speech Recognition (ASR) and Text-to-Speech (TTS).
This dataset captures naturalistic code-switching between English and Twi, a common communicative practice in post-colonial contexts, and aims to advance speech and language technology for this underserved linguistic context.
